# 过渡期豁免台账（PRD-147/T2 落文件）

> 字段与规则以 PRD-147/T1 checklist v0.1 第 5 节为准。一行 = 一条豁免；
> `scripts/eng_checklist.py` 按本表解析：`对象` 列填 `repo` / `skill:<name>` /
> `plugin:<name>`（与报告里的对象串一致），命中后该条目输出 `EXEMPT` 并从达标率
> 分母剔除。**阻断级条目填了即台账本身违规**（脚本会报警告并按原分计）。

## 规则（T1 §5）

1. 阻断级不可豁免；
2. 同一对象同时有效的豁免 ≤3 条；
3. 同一条目不得连续豁免两次——第二次必须修复或立跟踪 issue；
4. 豁免条目从达标率分母剔除（同 N/A 待遇），但在报告里标 `EXEMPT` 而非空白；
5. 到期自动失效；批准人不得与该条目的实现者是同一人（生成者 ≠ 采纳人）。
