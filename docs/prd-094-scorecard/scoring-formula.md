# PRD-094/T2：汇总公式说明

> 口径来源：《PRD-094/T1 checklist v1（定稿）》"汇总口径"第 1–8 条与"决策记录"。本文件只把口径写成可计算公式，不新增标准。

## 记号

对某打分对象（一个 skill / 一个插件 / 仓库整体）：
- 适用条目集 S：该层级条目中未标 N/A 者。标 N/A 必须写明不适用理由，N/A 不进任何分母。
- 每条得分 s ∈ {0, 1, 2}：2 = 完全满足，1 = 部分满足，0 = 缺失或违反（判定条件以定稿条目表为准）。
- 层级条目集：skill 级 10 条（C-01、C-16、C-17、C-18、C-19、C-24、C-25、C-29、C-30、C-31）；插件级 15 条（条目表"适用"列含"插件"者：C-02、C-06、C-07、C-09、C-10、C-11、C-12、C-13、C-14、C-15、C-20、C-22、C-23、C-27、C-28）；仓库级 6 条（C-03、C-04、C-05、C-08、C-21、C-26），另 C-22、C-27 在仓库层各有一次整体核查行（双层适用）。

## 公式

1. **实得分** = Σ s（i ∈ S）
2. **得分率** = 实得分 ÷（|S| × 2）
3. **达标率** = |{ i ∈ S : s = 2 }| ÷ |S|
4. **单对象达标判定（Q5 已确认）**：达标 ⟺ S 中无 0 分 **且** 达标率 ≥ 90%。
5. **部分达标 / 不达标**：得 1 分为部分达标、0 分为不达标；1 分与 0 分条目全部进 T4 待办清单（0 分优先）。
6. **三层分开报（Q4 已确认）**：skill、插件、仓库三层各自按上面公式出分并分开报告，**不折算任何总分**。
7. **整体验收（T5，PRD 口径）**：覆盖率 = 已打分 skill 数 ÷ 20（Q1 口径 20/20）；复核一致性 = 抽查 5 个 skill 时复核分数与原分数一致的条目占比，要求 ≥ 80%。
8. **证据规则**：无证据的打分视为未打分（不进 S，也不算覆盖）；标"待复核"的条目正常计分，另进 T5 抽查池。
