# PRD-335/T1 设计：生成式 UI

> trend issue #1614 · 借鉴 vercel-labs/json-render（Apache-2.0，实测）

## 目标

插件配置页由模型返回组件树、渲染器流式渲染，非法属性丢弃，预览与最终形态同一组件库。

## 方案要点

- 组件树 schema：节点类型白名单，非法属性丢弃不渲染
- 流式渲染：组件树到达即逐步上屏
- 预览与最终形态同一渲染器（零双轨）

## 任务拆分

1. T1（本层）：设计文档与验收口径；
2. T2：最小实现（有测试）；
3. T3：闸门/深化（有测试）；
4. T4：划界断言（有测试）；
5. T5：验收试运行（全链跑通）。

## 红线

- 文档与示例零真实主机名/IP/账号/密钥。
- 各仓既有红线继续生效。
