## 1. 借鉴对象、许可证与不复用红线

借鉴对象：macro-inc/macro，**AGPL-3.0（2026-10-29 经 GitHub License API 实测）**。

- **复用**：仅借鉴「@引用、不复制」的**操作形态**（引用名 → 解析元信息 → 不搬正文）。
- **不复用**：AGPL-3.0 传染性——**零代码复用、零依赖引入**；解析器（T2）自研，风格对齐本仓既有「总登记册 + 双载体同源 + 校验器」纪律（skill_registry / pack_installer 同族：登记表驱动、机判、诚实报错）。

## 3. @语法

### 3.1 形态（T2 实现口径）

| 形态 | 示例（占位） | 解析目标 |
|---|---|---|
| skill 引用 | `@基础技能` | 被引用 skill 的触发条件 + 输出契约 |
| 位置 | 出现在引用方 SKILL.md 的 `references:`（或 frontmatter `x-references:`）字段 | 逐条解析，登记进引用方元数据 |

### 3.2 禁止形态（出现即 `REF_SYNTAX_ERROR`，不尝试理解）

- `@基础技能#正文`——引用不带节锚（正文永不引用，R1）；
- `@基础技能 v2`——引用不带版本后缀（版本归属 PRD-227 包版本管理，skill 名全库唯一即是身份）；
- 自引用 `@自己`——拒绝（`REF_SELF_LOOP`，防环）。

## 4. @名→契约解析 schema

### 4.1 产物 schema（T2 预埋）

```json
{
  "schema": "skill-ref-resolution/v1",
  "raw": "@基础技能",
  "skill": "zh-基础技能（占位名）",
  "trigger_conditions": ["触发句式一（占位）", "触发句式二（占位）"],
  "output_contract": {"artifact": "…（占位）", "fields": ["…"]},
  "resolution": {"status": "resolved", "candidates": 1, "strategy": "exact"}
}
```

- `trigger_conditions` 取自被引用方 frontmatter `description` 的触发句式段（PRD-199/T2 口径已含 Use when/时使用 结构）——**摘录触发句，不摘录其余 description 文本**；
- `output_contract` 取自被引用方 `metadata.output`/验收例结构（登记册已有机械派生口径，PRD-227/T3），不读正文。

### 4.2 解析步骤（确定性）

1. 取候选集：总登记册 registry.json（PRD-227/T3 产物，全库唯一 skill 名）；
2. 精确匹配 skill 名全等；
3. 候选数裁决：=1 resolved；=0 `REF_NOT_FOUND`；同名冲突在登记册层已被 `check_conflicts` 拒绝（登记册不变量），故 >1 不应出现——出现即登记册损坏，报 `REF_REGISTRY_CORRUPT`；
4. 解析触发条件与输出契约（§4.1 口径），零正文读取。

## 5. 失败报错不降级（T3 预埋）

| 错误码 | 触发 | 行为 |
|---|---|---|
| `REF_SYNTAX_ERROR` | §3.2 禁止形态 | 报错回显位置，引用方加载失败显形 |
| `REF_NOT_FOUND` | 登记册无此名 | **报错**：不静默跳过、不空契约占位——引用方整体不可用（fail-closed），错误信息列出可用 skill 名摘要 |
| `REF_SELF_LOOP` | 自引用 | 拒绝 |
| `REF_CYCLE` | 引用环（A→B→A） | 拒绝：解析时做环检测（DFS），环成员全部显形 |
| `REF_REGISTRY_CORRUPT` | 登记册不变量破坏 | 报错（数据问题显形，不掩盖） |

- 词表封闭；解析返回 `Contract | Refusal` 二型；"降级路径不可达"由组装器类型保证（只接受 Contract）。

## 6. 引用关系审计

- 每次解析追加：`{ts, from_skill, raw, to_skill, status, error_code?}`；
- 从审计可重建全库引用依赖图（供 T3 环检测复核与文档化）；
- 引用关系同时落引用方 frontmatter `x-references`（静态可查）+ 审计（动态可查）——双载体同源口径沿用 PRD-227。

## 7. 禁止全文复制的边界（R1/R3 展开）

- 引用产物字段白名单：`trigger_conditions`、`output_contract`、`to_skill`（身份）——**没有** body/examples/steps 通道（组装器类型层面不存在）；
- 被引用方 SKILL.md 更新后，引用方**不**缓存旧契约——每次解析现读登记册/源文件（引用即最新，防漂移）；若要"钉住版本"，走 PRD-227 包版本，不走引用缓存。
