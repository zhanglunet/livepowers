# PRD-046/T2：存量 19 skills 简洁输出改造清单

> 状态：清单。只盘点、不改代码；改造执行是下一步。
> 依据：`docs/plans/2026-10-17-concise-output-spec.md` v0.1（三段式：结论≤50字 / 关键信息≤5条各≤30字 / 详情折叠；四类场景；`LIVEPOWERS_VERBOSE=1` 开关）。
> 盘点范围：`skills/` 下 19 个 skill 的人类可读输出 = skill 文档展示/引用的命令输出 + skill 要求的 agent 汇报格式。命令实现在 `scripts/lp.py`（92 处 print）、`scripts/agent_switch.py`、`scripts/scan_sqlite.py`、`scripts/scan_sql.py`、`scripts/eval_triggers.py`。
> 机器可读输出（`--json`、JSON/JSONL 落盘、hook 协议 JSON、退出码语义）**不在改造范围**，见 §6 高风险清单。

## 0. 盘点口径

- 类别标注：[执行]=执行结果类 / [诊断]=诊断类 / [错误]=错误类 / [查询]=查询类。
- 差距分级：大（全文无结构，需按三段式重排）/ 中（有结论但缺三段式或缺折叠）/ 小（微调，如补结论行、加折叠提示）/ 无（已符合）。
- 风险备注：高 = 被下游脚本/CI 解析或机器协议，改造时原文保留（只动人类可读部分）；中 = 可能被复制进文档/汇报；低 = 纯人阅读。
- 开关说明：规范 §4 的 `LIVEPOWERS_VERBOSE` 落地是 T3 的事；本清单所有"目标格式"均按"默认简洁、开关回全量"来写，T2 改造时预留开关位。
