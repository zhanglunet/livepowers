# 瘦身门 T5 验收演示：虚构新 skill 完整走一遍（2026-10-23）

> 对应 trend issue [#744](https://github.com/zhanglunet/trend/issues/744)（PRD-148/T5）。
> 验收标准：**新 skill 走通瘦身门；至少 1 次合并或拒绝案例留档**。
> 演示对象 `slim-gate-demo-skill` 是**虚构提案**：只存在于测试夹具（临时目录搭的最小
> 仓库骨架），不入 `skills/` 正式目录、不进路由表；人员字段全为占位符，无真实账号。

## 1. 演示口径

- 门禁脚本：`scripts/slim_gate.py`（T2，CI 每次 push / PR 硬检查）；published 锚点 =
  ①`using-livepowers` 路由表 ②根 README 技能表 ③插件拷贝（三处齐 = published）。
- CI 口径 = 脚本退出码：**有违规 exit 1（打回），全过 exit 0**。
- 复现：`python3 -m unittest tests.test_slim_gate_t5 -v`（夹具与三阶段断言即本文档的机检化）。

## 2. 三阶段走门记录（拒绝 → 补记录 → 通过）

| 阶段 | 夹具状态 | 门禁结果 | 语义 |
|---|---|---|---|
| ① 未登记 | 虚构 skill 只在 `skills/` 目录，三处登记缺 ②③ | **exit 0**，报告标"未发布（缺 ②根 README 技能表、③插件拷贝）" | 未视为 published，不要求记录——门只拦"发布"，不拦"起草" |
| ② published 无记录 | 补齐三处登记（路由表行 + README 行 + 插件拷贝） | **exit 1**，违规文案：`skill \`slim-gate-demo-skill\` 已三处登记（published）但缺瘦身门决策记录：补 docs/slim-gate/records/<YYYYMMDD>-…（模板 templates/slim-gate-record.md），或走 rejected/merged 处置` | CI 口径拒：无记录不可标为 published（T1 §1/§7 规则） |
| ③ 补决策记录 | 按 `templates/slim-gate-record.md` 补一条五问全 pass 的 approved 记录 | **exit 0**，报告行：`OK  slim-gate-demo-skill  published  记录 …：decision=approved status=provisional` | 过门。构造证据 → 按 T1 §3 只能 provisional，真实记录补齐后转 final |

留档：阶段 ③ 的决策记录即
[`records/2026-10-23-slim-gate-demo-skill.md`](records/2026-10-23-slim-gate-demo-skill.md)
（SG-20261023-01，「拒绝 → 补记录 → 通过」案例样例；`scripts/slim_gate.py` 会将其采信为
格式合规的有效记录，但对应 skill 不在 `skills/`，对真实发布检查零影响）。

## 3. 反向对照（终态不可逆，T1 §3）

同一夹具若补的是 `decision: rejected` 记录（或 proposer=reviewer 的无效记录），门禁同样
exit 1：published 但最新记录不是 approved → 依旧打回。断言见
`tests/test_slim_gate_t5.py`（沿用 T2 既有用例口径，本演示复跑确认）。

## 4. 变体：相似检测提示 → 并入已有 skill（Q2 输入）

构造一个与已有 skill 触发条件近重复的虚构提案（夹具内两份 SKILL.md，英文触发段几乎
相同），`scripts/skill_similarity.py`（T3，只提示不判定、退出码恒 0）输出：

```text
○ 相似对：<提案A> × <存量B>（≥0.60，主相似字段 en）| 重叠触发词：…
```

处置走向：提示 ≠ 判定 → 决策记录 Q2 填 `merged`（括注目标 `<目标skill>#<节名>`）、
decision 填 `merged`、`changes` 列并入清单——并入后**不做三处登记**，门禁保持 exit 0。
本演示留档的是第 2 节的「拒绝 → 补记录 → 通过」型；merged 型按同一模板填法，字段级
定义见 `templates/slim-gate-record.md`（T1 §3）与 `docs/slim-gate/README.md`。

